🔥 How to Attach Firebase

Aap bohot asani se apni Firebase is project me attach kar sakte hain:

  1. Firebase Console Kholain:
    https://console.firebase.google.com/ par ja kar naya project banayein.
  2. Authentication & Realtime Database Enable Karen:
    Left sidebar me Build > Authentication > Get Started me Email/Password aur Google on karein. Sath hi Realtime Database create karein.
  3. Web App Credentials Copy Karen:
    Project Settings (Gear icon) me General > Your apps > </> Web register karen aur firebaseConfig credentials copy karein.
  4. js/firebase-config.js Me Paste Karen:
    Is project ke file js/firebase-config.js me jakar placeholder keys ko apne real keys se replace kar dein:
